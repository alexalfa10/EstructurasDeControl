Estructuras de Control

Asignatura: Técnicas de Programación  
Lenguaje: Java  
IDE: Apache NetBeans

Descripción

Este repositorio contiene 11 ejercicios prácticos desarrollados en Java, relacionados con las estructuras de control y los fundamentos de programación.

Contenido

1. Ingreso y visualización de datos personales.
2. Operaciones matemáticas básicas.
3. Verificación de mayoría de edad.
4. Aprobación o reprobación de un estudiante.
5. Clasificación de calificaciones.
6. Uso de la estructura `switch` para identificar los días de la semana.
7. Ingreso de números y cálculo de su suma y cantidad.
8. Validación de contraseña.
9. Tabla de multiplicar.
10. Cálculo de suma y promedio de diez números.
11. Identificación del número mayor y menor.

Herramientas utilizadas

Java.
Apache NetBeans.
GitHub.
